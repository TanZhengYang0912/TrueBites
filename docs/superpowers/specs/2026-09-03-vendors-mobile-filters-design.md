# Vendors 手机端筛选栏统一设计

日期：2026-09-03

## 目标与范围

手机端的 Vendors 筛选栏改为单列、等宽、等高且整齐对齐的布局。保留现有桌面 UI、配色、交互和全部筛选功能。

本次只调整 `frontend/src/pages/admin/AdminVendorManagementPage.jsx` 的筛选工具栏及其必要的局部样式，不调整顶部导航、侧栏、商家表格、确认框或其他管理页面。

## 已确认的设计

采用单列全宽方案，不采用双列混排或折叠筛选抽屉。手机上的排列顺序维持为：

1. 搜索框。
2. List / Map 切换容器。
3. Category 下拉框。
4. Status 下拉框。
5. Sort 下拉框。
6. Possible duplicates 按钮（有重复记录时显示）。
7. Export PDF 按钮。

每项占满当前内容区宽度，左右边缘一致；外框高度统一为 52px，相邻项垂直间隔 12px，控件文字统一为 14px。保留现有圆角胶囊、图标和颜色。List / Map 在同一外框内各占一半，内部按钮保留至少 44px 的点击高度。

搜索文字和下拉内容左对齐，下拉箭头采用一致的右侧内边距；操作按钮内容居中。小屏幕上仍需完整显示操作含义，不让工具栏产生横向页面溢出。

## 响应式边界与实现约束

- 手机布局仅在视口宽度小于 768px 时生效。
- 768px 及以上保持现有工具栏布局与尺寸，不修改桌面基础样式。
- 使用 Vendors 专属的局部布局钩子及手机断点样式，避免影响其他页面的公共控件。
- 注意现有管理端移动样式规定的 44px 最小点击高度，避免内部按钮撑出切换容器。
- 保留现有数据来源、状态、事件处理和排序逻辑；不修改后端、权限或 PDF 内容。
- Duplicates 不显示时不留下空行。Export PDF 的禁用和 Preparing PDF 状态不改变控件尺寸。
- 商家表格原有的横向滚动行为维持不变。

## 验收与验证

- 在 320、390、430、767px 宽度检查：所有工具栏控件等宽、52px 高、12px 间距，边缘对齐，无工具栏溢出；List / Map 内部等宽。
- 在 768、1280、1440px 对照修改前的截图或尺寸基线，确认桌面及非手机布局没有改变。
- 检查有／无重复记录、长类别名称和 PDF 准备状态，确认布局稳定。
- 使用模拟 API 数据验证搜索、类别、状态、排序、List / Map 切换与导出入口仍能正常工作，不修改真实商家数据。
- 运行相关浏览器回归测试、单元测试和前端构建。
- 实施开始与最终验证前检查独立复核任务，安排 luna_worker 进行范围及桌面回归审查。
