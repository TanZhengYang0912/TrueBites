# Vendors 手机端筛选栏统一设计

日期：2026-09-03；修订 2：手机端两列布局。

## 目标与范围

手机端的 Vendors 筛选栏采用两列等宽布局，搜索和较长的控件保留整行。保留现有桌面 UI、配色、交互和全部筛选功能。本修订替代之前的手机单列排法；已完成的单列实施计划仅保留为历史记录。

本次只调整 `frontend/src/pages/admin/AdminVendorManagementPage.jsx` 的筛选工具栏及其必要的局部样式，不调整顶部导航、侧栏、商家表格、确认框或其他管理页面。

## 已确认的设计

采用用户已确认的两列等宽方案，不增加折叠筛选抽屉。手机上的视觉排列为：

1. 搜索框：占整行。
2. List / Map 切换容器：占整行。
3. 左侧 Category，右侧 Status：并排，各占扣除间距后的一半宽度。
4. 左侧 Sort，右侧 Export PDF：并排，两项与上一行的对应列等宽且边缘对齐。
5. Possible duplicates：占整行，位于上述控件之后，仅在有重复记录时显示。

所有控件外框高度统一为 52px，行间距和两列之间的间距均为 12px，控件文字统一为 14px。整行控件占满当前内容区，两列控件等宽，不依赖文字长度决定宽度。保留现有圆角胶囊、图标和颜色。List / Map 在同一外框内各占一半，内部按钮保留至少 44px 的点击高度。

搜索文字和下拉内容左对齐，下拉箭头采用一致的右侧内边距；操作按钮内容居中。在 320px 手机上仍保留两列，不能让长内容撑宽列或产生页面横向溢出。长类别选中值可在收起的控件内截短，但展开选项仍保留完整名称；按钮文字（包括 Preparing PDF…）可在固定高度内换行，不能被遮挡。

## 响应式边界与实现约束

- 手机布局仅在视口宽度小于 768px 时生效。
- 768px 及以上保持现有工具栏布局与尺寸，不修改桌面基础样式。
- 使用 Vendors 专属的局部布局钩子及手机断点样式，避免影响其他页面的公共控件。
- 桌面保留原有控件排列；手机端的键盘焦点顺序与其视觉排列一致，不能因位置调换而来回跳行。
- 注意现有管理端移动样式规定的 44px 最小点击高度，避免内部按钮撑出切换容器。
- 保留现有数据来源、状态、事件处理和排序逻辑；不修改后端、权限或 PDF 内容。
- Duplicates 不显示时不留下空行。Export PDF 的禁用和 Preparing PDF 状态不改变控件尺寸。
- 商家表格原有的横向滚动行为维持不变。

## 验收与验证

- 在 320、390、430、767px 宽度检查：Category / Status 和 Sort / Export PDF 各自同一行、两列等宽、上下列边缘对齐；整行控件占满内容区。所有外框 52px 高，行列间距 12px，无工具栏溢出；List / Map 内部等宽。
- 在 768、1280、1440px 对照修改前的截图或尺寸基线，确认桌面及非手机布局没有改变。
- 检查有／无重复记录、长类别名称和 PDF 准备状态，确认半宽控件不变形、文字可读、无多余空行；检查手机键盘焦点顺序。
- 使用模拟 API 数据验证搜索、类别、状态、排序、List / Map 切换与导出入口仍能正常工作，不修改真实商家数据。
