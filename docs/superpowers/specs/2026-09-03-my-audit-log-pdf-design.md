# My Audit Log — Export PDF

## 已确认的需求

- 在 My Audit Log 页面添加 Export PDF 按钮，放在右上角 View Site 下方、表格上方的内容区，靠右对齐。
- 导出当前登录管理员自己的全部操作记录，不限网页当前页的 25 条。
- 保留网页上的 When、Action、Entity 三栏；长内容自动换行，记录跨页展示。
- 不增加其他管理员的记录，也不把 My Audit Log 改为全站审计页面。

## 方案与边界

已比较只导出当前页和导出全部自己的记录；用户选择后者。沿用现有分页接口和前端 PDF 工具，不新增报表服务、数据库表或公开下载接口。

### 页面与交互

- 按钮沿用管理后台现有样式与下载图标；只出现在 My Audit Log 页面，不移动 View Site 或其他页面按钮。
- 窄屏下保持在表格上方，不造成横向溢出。
- 准备期间显示 Preparing PDF… 并禁用重复点击；读取或生成失败显示可重试错误，不清空网页表格。
- 准备期间离开页面或切换登录身份时取消该次导出；已经成功打开的 PDF 不会因离开页面被关闭。
- 空记录可以导出带标题、三列表头和 No recorded activity 提示的 PDF。

### 数据与权限

- 通过 `getMyActivity` 顺序读取全部页，每页 100 条，遵守服务器上限，不使用其他用户的 activity 接口。
- 接口使用服务器验证的当前用户 ID 过滤 `actor_id`，客户端不能指定其他管理员；本次不改变权限配置。
- 保留接口的新到旧顺序；单页失败即停止，不把部分结果当作完整导出。
- 仅映射日期、动作、实体类型及网页已经显示的实体 ID。不得输出原始 `metadata`、令牌、原因详情、来源 URL 或隐藏的 API 字段。
- 网页与 PDF 共用日期、动作和实体的显示规则，避免大小写或空值显示不同。
- 本次沿用现有分页查询语义，不声称多次请求构成数据库事务快照；不新增实时订阅或后台导出任务。

### PDF 与资源处理

- 使用可搜索、可复制的 PDF 表格，不截图网页；采用 A4 横向、后台蓝灰配色、TrueBites 和 My Audit Log 标题、生成时间、记录总数及页码。
- 各页重复 When、Action、Entity 表头，实体 ID 和长动作名换行，不裁切实际记录；复用已具备的本地字体支持。
- 点击时同步预留预览窗口，读取数据后展示 PDF；弹窗被阻止时给出明确提示。失败关闭空白窗口，结束后清理不用的 blob URL。
- 不上传 PDF 到公共目录或第三方，不改变 Dashboard 和其他列表导出的既有行为。

## 验收

1. 桌面按钮位于 View Site 下方、表格上方右侧；窄屏没有布局溢出。
2. 超过 100 条的测试数据能跨接口页完整导出，顺序、数量和三栏内容正确，且不依赖当前网页页码。
3. PDF 中不含 metadata 等隐藏字段；检查当前管理员的接口和权限边界。
4. 验证空记录、分页请求失败、重试、重复点击和弹窗被阻止。
5. 生成真实测试 PDF，检查分页、长文本、文字提取和视觉布局；运行相关单元、浏览器测试及生产构建。
6. 实现开始及最终验证时检查独立子任务，使用 luna_worker 进行有边界的权限或质量复核。

## 状态

- 已完成页面及现有导出工具检查，luna_worker 已独立确认接口的个人范围、分页上限和 metadata 隐私边界。
- 用户已确认书面规格并要求执行；页面、完整分页导出、共享格式化和可复制 PDF 已实现。
- 最终验证：152 项单元测试、24 项浏览器测试、生产构建和差异检查通过；真实 PDF 已逐页检查。独立复核意见已修复并复核通过。
