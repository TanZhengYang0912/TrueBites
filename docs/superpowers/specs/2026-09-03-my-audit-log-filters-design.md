# My Audit Log — 统一筛选 UI 与 PDF 导出条件

## 目标与范围

用户已确认本次只调整 My Audit Log：沿用 Vendors 的筛选控件样式，PDF 导出全部符合当前筛选条件的个人记录，并保持网页所选排序。Vendors、Dashboard 及其他页面的业务行为不变。

用户已确认本设计并要求执行；实现与验证已完成。

## 方案

推荐后端筛选、排序后再分页，网页与 PDF 共用同一份查询条件。另一种方式是前端读取数据后筛选，但只筛当前页会漏记录，读取全部再筛又会增加日常浏览成本，因此不采用。

保留现有个人日志接口、PDF 表格生成器及本地字体，不新增数据库表、报表服务或全后台筛选框架。

## 筛选栏与交互

筛选栏放在 View Site 下方、日志表格上方的内容区。沿用 Vendors 的白底圆角搜索框、圆角下拉框、蓝色文字按钮、控件高度和间距；Export PDF 位于筛选栏右侧，窄屏自然换行。不会复制日志页不适用的 List/Map 或重复商家提醒。

- 搜索：匹配 Action 或 Entity 类型文字，不区分大小写；完整 UUID 搜索同时支持 Entity ID 精确匹配。提示明确说明支持的字段，不搜索隐藏 metadata。
- Entity：默认 All entities；选项覆盖现有代码写入的实体类型。新增或自定义实体仍能在 All entities 中显示并通过搜索找到，不从当前页的 25 条记录临时生成选项。
- 时间：Any time、Today、Last 7 days、Last 30 days、Last 90 days。按 Asia/Kuala_Lumpur 的日历日计算，最近 N 天包含今天；起点包含、终点为明日零时且不包含。不增加自定义日期选择器。
- 排序：Newest first（默认）、Oldest first。以创建时间排序，时间相同时按记录 ID 升序，避免翻页顺序不稳定。
- Clear filters：存在非默认条件时可用，一次恢复默认条件与第一页。

搜索沿用 Vendors 的短延迟输入方式；任意已应用条件改变后回到第一页，仍每页 25 条。取消过期请求，避免旧请求覆盖新结果。显示符合条件的记录总数；无匹配结果时明确说明并可清除条件。

## 查询与权限

- 网页列表与导出使用统一、规范化的查询对象，包括搜索、实体类型、时间起止与排序。
- 时间预设在应用筛选时解析一次；翻页和导出复用相同起止时间，避免跨午夜时每页计算出不同范围。
- 后端先应用当前管理员 actor_id 与全部条件，再计算总数、排序、分页。客户端不能传入其他管理员身份。
- 搜索限制长度，并安全处理查询语法及通配字符；无效时间、实体筛选或排序参数明确拒绝，不意外退化成无条件查询。
- Action 和 Entity ID 不假定为数据库枚举；普通搜索不因任意历史动作文本而失败。UUID 精确搜索仅是受支持的搜索入口，不改变已有记录。
- 不读取或导出 metadata、令牌、来源 URL、其他管理员资料。无需未经确认的数据库迁移；仓库未提供可验证的 audit_log 索引定义，不声称已优化索引。

## PDF 一致性

- 点击 Export PDF 时固定当前已应用的查询和排序；输入仍在等待应用或当前查询尚未加载成功时禁用导出，避免搜索框与报告不一致。
- 使用固定条件读取全部匹配页，不限网页当前页；准备期间即使改变筛选，已开始的报告仍使用点击时条件。
- 保留 When、Action、Entity 三栏及共享显示格式，顺序与同条件网页一致。
- 报告标明筛选条件、排序、匹配记录总数和生成时间。长搜索文字自动换行，动态预留页眉空间，不挤压或覆盖表头与记录。
- 保留可搜索文字、Unicode 字体、分页表头、页码、空结果报告，以及弹窗被阻止、失败重试、防重复点击和离开页面/切换账号取消的既有行为。
- 任一分页失败即不生成部分报告。不声称多次分页读取是数据库事务快照；导出期间后台数据变化仍沿用现有接口语义。

## 验收

1. 桌面及窄屏筛选栏与 Vendors 控件风格一致，无水平溢出；不改变其他页面。
2. 搜索、实体、时间、排序和清除能组合使用；切换条件回到第一页，迟到请求不覆盖新查询。
3. 超过 100 条的夹具中，网页计数、全部匹配记录、PDF 数量及新旧排序一致；同时间记录有稳定顺序。
4. 验证马来西亚日界线、时间范围边界、无匹配记录、特殊搜索字符和无效查询参数。
5. 导出跨多页时条件不变；准备期间更改筛选不改变该报告，翻页失败不生成部分 PDF。
6. 验证当前管理员隔离、隐藏字段不被搜索或导出，以及现有取消、重试和弹窗行为。
7. 生成真实 PDF，检查筛选摘要、长文本与 Unicode 的换行、分页及文字提取；运行相关单元、浏览器测试和生产构建。
8. 实现开始及最终验证时安排有边界的 luna_worker 独立复核。本次设计阶段已复核接口权限范围、动作与实体字段约束。
